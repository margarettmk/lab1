# Лабораторная работа № 1
Сбор информации об операционной системе средствами Python

### Описание

Программа представляет собой кроссплатформенный скрипт на Python, предназначенный для определения текущей операционной системы и сбора основных сведений о программной и аппаратной конфигурации компьютера.

Скрипт поддерживает Windows, Linux и macOS. После запуска программа автоматически определяет операционную систему, собирает системные параметры и сохраняет полученную информацию в файл `os_info.json`.

Для выполнения работы используются только модули стандартной библиотеки Python. Системные консольные утилиты операционной системы для получения информации не используются.

### Собираемые параметры

Скрипт собирает следующие сведения:

- дата и время сбора информации;
- название операционной системы;
- тип платформы;
- тип системного интерфейса (`nt` или `posix`);
- версия операционной системы;
- версия ядра системы для Linux и macOS;
- название дистрибутива Linux;
- имя компьютера;
- архитектура системы;
- сведения о процессоре;
- количество логических процессоров;
- общий объём оперативной памяти;
- общий объём дискового пространства;
- занятый объём дискового пространства;
- свободный объём дискового пространства;
- часовой пояс;
- системная кодировка;
- версия Python;
- реализация Python;
- путь к используемому интерпретатору Python.

### Используемые модули

В программе используются модули стандартной библиотеки Python:

`sys`, `os`, `json`, `socket`, `platform`, `shutil`, `time`, `locale`, `datetime`, `pathlib`, `ctypes`.

Внешние библиотеки не используются, поскольку необходимые данные можно получить средствами стандартной библиотеки Python.

После выполнения программы рядом со скриптом создаётся файл: os_info.json. Он содержит собранную информацию в формате JSON.
